# Bruce Effect Camera

Chrome 插件：给任何调用摄像头的网页加上**虚拟背景**（模糊 / 自定义图片）。

适用于本身没有虚拟背景功能的网页应用。

## 安装

1. 访问 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹

## 使用

1. 点工具栏的 B 图标，选择模式：无 / 模糊 / 自定义图片
2. 刷新摄像头所在的网页让效果生效
3. 之后调整滑块或换图，无需刷新即可实时生效
